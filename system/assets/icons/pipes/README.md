# Pipes icon families

Two families, both derived from the project's own standard artwork and both
generated by `scripts/make_pipes_icons.py`:

- **-30002** — the `Pipes` folder. The original standard folder family (`-3999`)
  with a pipe motif across its body.
- **-30003** — a named pipe. The original standard document family (`-4000`) with
  the same motif.

Each family carries `ICN#`, `icl8`, `ics#` and `ics8` at 32×32 and 16×16, so both
sizes and both colour depths draw the same glyph. The source families are
extracted from the System's own resources into `system/extracted_assets`, so
nothing here is drawn from outside the repository; the motif is the only added
artwork.

The four PNGs per family are the reviewable source. The `.bin` files beside them
are the resource payloads the manifest names, encoded with
`scripts/iconconvert.py`'s own helpers: monochrome payloads from the `1bit`
artwork and colour payloads from the `color` artwork, so neither is derived from
the other by conversion.

The `PIPE`/`PIPE` type pair reaches **-30003** through a `BNDL`/`FREF` pair, the
same mechanism the font suitcase uses: the bundle's signature is the creator, its
`FREF` names the type and the local icon id, and its `ICN#` mapping carries the
real family id. Icon Manager lookup therefore resolves the type without the
Finder keeping a table of its own.

Regenerate after changing the motif:

```sh
python3 scripts/make_pipes_icons.py --repo .
```
